# 可以"走进去"的论文攀岩墙 — 设计

日期：2026-11-16　规模：小改动（短设计）

## 意图

主页改成纯白背景后，论文攀岩墙看起来像一块边缘模糊的灰色方块。目标是让它变成一个"能走进去的真实空间"：没有边框，有纵深，动作安静克制，不打扰读论文。

## 目标

- 用 CSS 3D 搭一个岩馆角落：正面主墙，上方一段向外倾的仰角墙，左右侧墙伸出画面，地上是软垫。
- 浅白墙配色：墙面接近白色，正面最亮，侧墙和仰角稍暗，用明暗表现空间；墙上有淡淡的螺栓孔点阵和板缝。四周渐隐到白色，看不到边。
- 论文岩点凸出墙面并带投影；灰色"未来岩点"分布在仰角和侧墙上。
- 视角缓慢跟随鼠标（样稿 v2 的速度：缓动系数约 0.022，闲置晃动周期 7–9 秒，幅度小）。
- 小人是新的手绘图片，站在墙脚的软垫上抬头看墙。悬停某块论文岩点时，他朝那边微微转一点（≤3°，约 0.6 秒）。

## 不做的事

- 不做攀爬动画（可活动小人的试验已否决）。
- 不改论文数据、弹窗内容、文字版论文列表。

## 必须避免的

- 快速或大幅度的晃动；用滚动驱动画面；页面布局跳动。
- 弹窗和岩点错位。
- 出现看得见的方框边缘。

## 约束

- 静态导出（vinext），不加新依赖。
- 系统开了"减少动态效果"，或者设备没有鼠标（触屏）时，视角保持静止。
- 弹窗打开时暂停视角跟随，保证弹窗和岩点对齐。
- 论文岩点仍然是有标签、可用键盘聚焦的按钮。悬停预览、点击固定的现有交互保持不变。

## 考虑过的方案

- 方向：A 静止的岩馆角落；**B 视角跟随鼠标（选定）**；C 滚动驱动镜头（会占住一屏、打断阅读）。
- 小人：可活动的代码小人，带真实攀爬动作（做了试验，否决）；代码画的站立小人（画风偏几何，和手绘岩点不统一）；**手绘站立图片（选定）**。
- 实现：**CSS 3D 变换（选定，就是样稿用的做法）**。WebGL/three.js 要加一个很重的依赖，对这个效果来说过度。预渲染的透视图片做不出真正的视差。
